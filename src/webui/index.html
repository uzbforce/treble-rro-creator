Addons

module

These are module addons. A live pick is a Settings value the module writes itself: it applies as soon as you make it, and again on every boot so it sticks. An overlay pick is a resource in the APK this build shipped: Apply writes it into that APK (with the sliders), and a reload makes the framework read it. Use default removes an addon — the line leaves addons.conf and, for an overlay, the resource leaves the APK, so the ROM's own value is used again.

Reset overrides?

Restores the overlay APKs this module shipped and discards the saved values. The framework restarts when something was actually applied; the build-time values come back with it.
